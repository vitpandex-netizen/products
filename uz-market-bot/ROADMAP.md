# Roadmap — uz-market-bot

> Актуально на август 2026

---

## ✅ P0 — Базовая функциональность *(Завершено)*

- Поиск по OLX.uz через открытое API
- AI-анализ через DeepSeek (OpenRouter)
- Диалоговый режим с уточняющими вопросами
- ConversationHandler (5 состояний)
- Агрегатор + ранжирование предложений
- Форматирование ответа в Telegram
- Работа из личных сообщений и из группового топика
- vault.py для безопасного хранения секретов

---

## ✅ P1 — Рефакторинг и улучшение поиска *(Завершено)*

- Удаление дублирующегося `_group_handler`
- Исправление Markdown в форматировании (убрано **жирное**)
- Групповой хендлер с правильным приоритетом (group=1)
- Фильтр `ChatType.GROUPS` для групповых сообщений
- Упоминание бота в группе (`@bot_username`) как триггер поиска
- IPv4-force для Telegram API на macOS
- Исправление regex для цен в запросах

---

## ⏳ P2 — Добавление Uzum.uz

**Статус:** Исследование API

**Задача:** добавить поиск по Uzum.uz — второй по величине маркетплейс Узбекистана.

**План:**
- Исследовать API Uzum.uz (см. `explore_uzum.mjs` — Playwright-скрипт для разведки)
- Создать `src/parsers/uzum_uz.py`
- Добавить в `Aggregator` как второй источник
- Единый формат `UnifiedOffer` для всех площадок
