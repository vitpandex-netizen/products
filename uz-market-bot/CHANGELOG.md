# Changelog — uz-market-bot

Все заметные изменения проекта фиксируются в этом файле.

---

## [1.1.0] — 2026-08-11

### Изменено
- Полный рефакторинг группового хендлера: удалён дублирующийся `_group_handler`
- Markdown-форматирование заменено на plain text (убрано `*bold*`)
- Групповой хендлер зарегистрирован с правильным приоритетом (group=1)
- Добавлен фильтр `ChatType.GROUPS` для групповых сообщений

### Добавлено
- Поддержка упоминания бота в группе (`@bot_username`) как триггер поиска
- IPv4-force для Telegram API на macOS (решение проблемы с AAAA-записями DNS)
- Обработчик для приватных сообщений без `/start` (group=2)

### Исправлено
- Дублирование метода `send_to_group` в market_bot.py
- Regex для цен в запросах (экранирование символов)

---

## [1.0.0] — 2026-08-08

### Добавлено
- Первый стабильный релиз
- Поиск по OLX.uz через открытое API
- Диалоговый режим с LLM-уточнением (DeepSeek через OpenRouter)
- ConversationHandler с 5 состояниями (QUERY, CLARIFYING, CITIES, SORT, RESULT)
- Агрегатор с ранжированием и фильтрацией
- AI-анализ результатов поиска
- Работа из личных сообщений и из группового топика
- `send_to_group()` — отправка результатов в группу AI Assistant — Family
- vault.py для безопасного хранения секретов

### Инфраструктура
- Docker Compose с томом для конфига и данных
- pm2 для production-запуска
- config/config.json + fallback на переменные окружения
