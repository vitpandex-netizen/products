# Scheduled Skills

> Навыки (skills) для Hermes Agent с автоматическим запуском по расписанию (cron / launchd). Мониторинг рынков, торговые уведомления и биржевые сводки.

## 📋 Описание

Коллекция Hermes-скиллов, каждый из которых выполняется по расписанию и отправляет отчёты, уведомления или обновления статуса. Скиллы используют `PROJECT_META.json` для конфигурации, данные с Yahoo Finance для рыночной информации и Telegram для уведомлений.

## 📁 Структура

```
.

│   └── SKILL.md                   # 3177 байт

│   └── SKILL.md                   # 2317 байт
├── midday-market-update/          # Дневной апдейт (14:00 Ташкент)
│   └── SKILL.md                   # 2410 байт
├── morning-market-briefing/       # Утренний брифинг (09:00 Ташкент)
│   └── SKILL.md                   # 3689 байт
├── .interpreter-rules             # Правила для Open Interpreter (automation, schedule)
├── .gitignore
```

## 🧰 Стек

- **Язык:** Python (Hermes SDK)
- **Расписание:** launchd / cron
- **Данные:** Yahoo Finance API
- **Уведомления:** Telegram (через Hermes notification-скиллы)
- **Временная зона:** Asia/Tashkent (UTC+5)

## ⏰ Расписание

| Скилл | Время (Ташкент) | Описание |
|---|---|---|
| **morning-market-briefing** | 09:00 | Утренний брифинг: открытие NYSE, азиатские рынки, ключевые события дня |
| **midday-market-update** | 14:00 | Дневной апдейт: динамика NYSE, корпоративные новости, изменения портфеля |
| **evening-market-summary** | 21:00 | Вечерний итог: закрытие NYSE, итоги дня, план на завтра |
| **hmmt4b2-trading-monitor** | Каждые N минут | Мониторинг начала торгов и цены облигации HMMT4B2 (Hamroh MMT) |

## 🔧 Использование

```bash
# Просмотр описания скилла
cat scheduled-skills/morning-market-briefing/SKILL.md

# Установка расписания через launchd
# (см. SKILL.md каждого скилла для точных инструкций)
```

## 🎯 Назначение

- Автоматизация рутинных рыночных отчётов
- Мониторинг специфических инструментов (облигации HMMT4B2)
- Своевременное информирование о рыночных событиях
- Основа для расширения на другие рынки и инструменты
