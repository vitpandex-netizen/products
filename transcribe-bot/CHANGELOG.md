# Changelog — transcribe-bot

Все заметные изменения проекта фиксируются в этом файле.

---

## [1.1.0] — 2026-08-06

### Добавлено
- Файловый вывод транскрипции: `send_document()` в `bot_api.py`
- Формат файла с таймстемпами `[MM:SS]` и именем `transcription_YYYY-MM-DD_HH-MM.txt`
- Поле `segments` в ответе сервиса, парсинг и форматирование

### Изменено
- `MAX_MESSAGE_LEN` увеличен для поддержки send_document
- `transcribe()` теперь возвращает `(text, segments)` вместо `text`

---

## [1.0.0] — 2026-07-??

### Добавлено
- Первый релиз: базовая транскрибация голосовых сообщений
- Long-polling цикл через Telegram Bot API
- Интеграция с transcribe-service (faster-whisper)
- RBAC: owner → admin → user
- Admin-панель с inline-кнопками
- Meeting Pipeline: DeepSeek-анализ → Notion

### Инфраструктура
- Docker Compose с общей сетью `transcribe-net`
- Персистентное состояние в `state.json`
- Поддержка self-hosted Telegram Bot API
