# Roadmap — transcribe-bot

> Актуально на август 2026

---

## ✅ P1 — Файловый вывод транскрипции *(Завершено 2026-08-06)*

**Что сделано:**
- Добавлена `send_document()` — отправка файла через multipart/form-data
- `transcribe()` возвращает `(text, segments)`
- Формат файла: `transcription_YYYY-MM-DD_HH-MM.txt` с таймстемпами `[MM:SS]`
- Fallback: если сегментов нет — отправка plain text как раньше

---

## ⏳ P2 — Диаризация (определение говорящих)

**Статус:** В очереди — ожидает реализации в transcribe-service

**Что будет в боте (после реализации в сервисе):**
- Если в сегментах есть `speaker` — формат файла:
  ```
  [00:00] SPEAKER_00: Привет всем
  [00:05] SPEAKER_01: Привет, как дела?
  ```
- Если нет `speaker` — текущий формат без имён
