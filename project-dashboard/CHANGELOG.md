# Changelog — Project Dashboard

Все заметные изменения в этом проекте.

## 1.0.0 (2026-08-09)

### ✨ Добавлено
- Первая полноценная версия дашборда
- HTTP-сервер на чистом Node.js (`server.js`, 462 строки)
- HTML-интерфейс (`dashboard.html`, 444 строки) с таблицей проектов и статусами
- Скрипт сбора метрик `collector.sh`
- Каталог проектов из `PROJECT_META.json`
- Мониторинг Git-статуса (чистые/грязные/без Git)
- Автоматическое сканирование `/Volumes/External/dev/`
- Сохранение метрик в `/tmp/dashboard-metrics.jsonl`
- Встроенный CSS для светлой темы

### 🛠 Исправления и техдолг
- Отсутствует `.gitignore` — добавлен при первой инициализации
- Нет Docker-образов — требуется Node.js окружение на железе

### 📝 Заметки
- Проект использует ESM (type: module в package.json)
- Порт по умолчанию: 3001
- Не является Python/FastAPI приложением, как указано в плане — реализован на Node.js
