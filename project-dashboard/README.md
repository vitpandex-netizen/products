# Project Dashboard

> Панель мониторинга проектов и сбора метрик. Визуализирует состояние всех проектов в `/Volumes/External/dev/`.

## 📋 Описание

Веб-сервер на Node.js (без фреймворков, чистый `http` модуль) для отображения и мониторинга проектов. Сканирует директорию разработки, собирает метрики Git-статуса, размеров и времени модификации, выводит их в удобном HTML-интерфейсе.

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск сервера (по умолчанию порт 3001)
npm start

# Или с указанием порта
PORT=8080 node server.js
```

Откройте `http://localhost:3001` в браузере.

## 📁 Структура

```
.
├── server.js            # HTTP-сервер (462 строки)
├── dashboard.html       # HTML-интерфейс (444 строки)
├── collector.sh         # Скрипт сбора метрик (2100+ строк)
├── PROJECT_META.json    # Каталог проектов
├── data/
│   └── metrics.jsonl    # Собранные метрики (JSONL)
├── package.json
└── package-lock.json
```

## 🔧 Функциональность

- **Обзор проектов** — таблица всех проектов из `PROJECT_META.json`
- **Git-статус** — чистые, грязные и неинициализированные репозитории
- **Метрики в реальном времени** — аптайм, количество файлов, размер директорий
- **Мониторинг сервисов** — проверка доступности внешних сервисов (Telegram, Oracle Cloud, портфель)
- **Ручное обновление** — кнопка «Update Metrics» в интерфейсе

## 🗺 Источник данных

Сервер ориентирован на `/Volumes/External/dev/` — внешнее рабочее пространство. Метрики собираются с помощью `child_process.execSync` и сохраняются в `/tmp/dashboard-metrics.jsonl`.

## 🧰 Стек

- **Runtime:** Node.js (ESM, `"type": "module"`)
- **Интерфейс:** Чистый HTML + CSS (встроенный в `dashboard.html`)
- **Данные:** JSON, JSONL, Git-статус
- **Порт:** 3001 (по умолчанию)
