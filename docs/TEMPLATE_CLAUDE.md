## Protocol Enforcement

This project follows the **Enterprise Agentic Protocol**:
- **Spec-First**: No code without SPEC.md
- **TDD-Lock**: Tests before implementation
- **Worktree Isolation**: Parallel tasks in `.worktrees/`
- **Zero-Tolerance**: No vibe-coding, no fake reporting

## Required Files

| File | Purpose | Status |
|------|---------|--------|
| `SPEC.md` | Technical contract | ✅ Required |
| `CHANGELOG.md` | Version history | ✅ Required |
| `CLAUDE.md` | Agent context | ⚠️ Recommended |
| `.worktrees/` | Task isolation | ⚠️ For complex tasks |

## Workflow

```bash
# 1. Check protocol compliance
python3 ~/dev/scripts/pre_impl_checklist.py . --verbose

# 2. Create worktree for task
~/dev/scripts/setup_worktree.sh TASK-XXX main

# 3. Implement in worktree
cd .worktrees/TASK-XXX
# ... code ...

# 4. Audit after deploy
python3 ~/dev/scripts/post_deploy_audit.py .. <commit-hash>
```

## Protocol Rules

1. **NO VIBE CODING** — Code only after spec + tests
2. **NO FAKE REPORTING** — "Done" requires test log
3. **NO TESTS AFTER CODE** — Test-first strictly
4. **NO MONOLITHIC CONTEXT** — Decompose complex epics
