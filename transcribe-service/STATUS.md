# Статус проекта — transcribe-service

> Обновлено: август 2026

---

## 📊 Общий статус: 🟢 Стабилен, активная разработка

| Аспект | Статус | Примечание |
|--------|--------|------------|
| Транскрибация (faster-whisper) | ✅ Работает | Модель medium, int8, CPU |
| API /transcribe | ✅ Работает | Multipart upload, JSON response |
| API /health | ✅ Работает | Docker healthcheck |
| ffmpeg-конвертация | ✅ Работает | Любой аудио/видео → 16kHz WAV |
| Очередь (asyncio.Lock) | ✅ Работает | 1 запрос за раз |
| Docker-сборка | ✅ Работает | python:3.12-slim |
| Диаризация | ⏳ В очереди | Исследование CPU-вариантов |
| Язык через параметр | 🔜 Планируется | Сейчас hardcode `ru` |

---

## 📈 Метрики (целевые)

- **Время транскрибации:** зависит от длины аудио
- **Доступность:** Docker Compose, restart: unless-stopped
- **Кеш модели:** персистентный, не перекачивается при перезапуске

---

## 🐛 Известные проблемы

| Проблема | Статус | Описание |
|----------|--------|----------|
| Очередь блокирует всех | 🔄 Планируется | asyncio.Lock — пока один пользователь транскрибирует, остальные ждут |
| Нет прогресса | 🔄 Планируется | Пользователь не знает, сколько осталось |
| Только русский язык | 🔄 Планируется | language="ru" hardcode |
