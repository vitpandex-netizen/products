## ⏳ P1 — Диаризация (кто говорит)

**Статус:** В очереди, исследование

**Задача:** добавить определение спикеров в сегменты транскрипции.

**Варианты:**
1. `pyannote.audio` — требует HuggingFace токен, тяжёлая модель
2. `whisperx` — альтернатива, может работать на CPU
3. `simple-diarizer` — лёгкая, без GPU

**План реализации:**
- Выбрать вариант, работающий в CPU Docker-контейнере
- Добавить опциональную диаризацию (env `DIARIZE=1`, по умолчанию выключена)
- Поле `speaker` в сегментах:
  ```json
  {"start": 0.0, "end": 5.2, "text": " Привет", "speaker": "SPEAKER_00"}
  ```
- Если диаризация отключена или не удалась — `"speaker": null`

**Ограничения:**
- CPU only (нет GPU в Docker на Mac)
- Базовый образ: `python:3.12-slim`
- Не ломать существующий API
