# ПРЕДУПРЕЖДЕНИЕ: ПРОЕКТ ПОД УПРАВЛЕНИЕМ ANTIGRAVITY 🛡️

Этот проект (`freqtrade-bgt` с 6 стратегиями) полностью управляется и поддерживается ИИ-агентом **Antigravity**. 

**Почему этот файл здесь:**
Мы перенесли этот проект с Mac на US Server (100.84.223.96), чтобы не нагружать рабочую машину. Чтобы избежать путаницы с проектами других агентов (например, DeepSeek/Hermes), все наши контейнеры и файлы помечены суффиксами `-ag` (Antigravity).

**Наши стратегии в этом репозитории:**
1. `EMA_Cross`
2. `RSI_Bollinger`
3. `SuperTrend`
4. `VWAP_RSI`
5. `ATR_Breakout`
6. `UltraScalper`

Пожалуйста, не вносите изменения вручную в рабочие файлы, чтобы не нарушить процесс тестирования и торговли.
