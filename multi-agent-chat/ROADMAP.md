# Roadmap — Multi-Agent Chat

> **Статус**: v1.0.0 — Production-ready MVP
> **Обновлено**: Август 2026

---

## Q3 2026 (текущий)

### 🔴 P0 — Критическое
- [ ] Добавить автоматический healthcheck для OpenRouter API
- [ ] Graceful shutdown для WebSocket соединений
- [ ] Логирование ошибок OpenRouter с алертингом

### 🟡 P1 — Важное
- [ ] **История чата** — просмотр и поиск по истории сообщений
- [ ] **Системный промпт** — возможность настраивать промпты агентов
- [ ] **Markdown-рендеринг** — улучшенный вывод кода и форматирования
- [ ] **Файловый обмен** — загрузка изображений и файлов в чат
- [ ] **CI/CD** — GitHub Actions + автоматический деплой

### 🟢 P2 — Улучшения
- [ ] Темная/светлая тема
- [ ] Экспорт чата (JSON, Markdown, PDF)
- [ ] Адаптация под мобильные устройства
- [ ] i18n (английский, русский, узбекский)
- [ ] WebSocket reconnect с exponential backoff

---

## Q4 2026

- [ ] **Agent switching** — выбор модели для каждого агента отдельно
- [ ] **Tool calling** — агенты могут вызывать функции (код, поиск, API)
- [ ] **Memory** — долговременная память для каждого агента
- [ ] **Session sharing** — публичные ссылки на сессии
- [ ] **Admin panel** — управление пользователями, мониторинг
- [ ] **API rate limit dashboard** — визуализация лимитов

## Q1 2027

- [ ] **Plugin system** — подключение кастомных агентов через API
- [ ] **Multi-modal** — поддержка изображений, аудио, видео
- [ ] **Voice input** — распознавание речи (Web Speech API)
- [ ] **Agent chaining** — последовательные вызовы агентов
- [ ] **OAuth** — вход через Google, GitHub, Telegram

## Q2 2027+

- [ ] **Desktop app** — Electron или Tauri
- [ ] **Mobile app** — React Native или Flutter
- [ ] **Enterprise SSO** — SAML, LDAP
- [ ] **Audit log** — полная история всех действий
- [ ] **Team workspaces** — командные пространства с ролями
