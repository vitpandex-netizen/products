# Meeting Pipeline — Roadmap

> Версия: 0.3.x
> Статус: **Активная разработка**

---

## Текущий спринт (v0.3.x)

### Приоритет 1 — Стабилизация

- [ ] **Обработка ошибок:** улучшить retry-логику при недоступности OpenRouter
- [ ] **Логирование:** добавить structured logging (JSON) для всех сервисов
- [ ] **Health check:** расширить — добавить статус Whisper, OpenRouter, Notion
- [ ] **Документация:** примеры для всех end-to-end сценариев

### Приоритет 2 — Функциональность

- [ ] **Поддержка Zoom/Meet/Teams API** — прямой импорт записей без rclone
- [ ] **Webhook после обработки** — уведомление в Telegram/Slack/email
- [ ] **Конфигурация через YAML** — вынести настройки из переменных окружения
- [ ] **Выбор модели Whisper** — поддержка large-v3 для лучшего качества

### Приоритет 3 — Улучшения

- [ ] **HTML-отчёт** — генерировать красивый HTML вместо JSON
- [ ] **История обработок** — хранить результаты в SQLite
- [ ] **Отмена обработки** — graceful shutdown долгих транскрипций

---

## Среднесрочные цели (v0.4.x — v0.6.x)

### Качество анализа

- [ ] **Multi-model анализ** — параллельный запуск нескольких AI-моделей для сравнения
- [ ] **Определение языка** — автоопределение и поддержка многоязычных транскриптов
- [ ] **Распознавание участников** — голосовая идентификация (diarization)
- [ ] **Тайм-коды** — привязка ключевых моментов к временным меткам
- [ ] **Векторный поиск** — семантический поиск по всем обработанным встречам

### Интеграции

- [ ] **Календарь (Google/Outlook)** — автоматическая привязка к событию календаря
- [ ] **CRM интеграция** — связывание встреч с контактами и сделками
- [ ] **Slack-уведомления** — пост саммари в канал после встречи
- [ ] **Jira/Linear** — автоматическое создание задач из action items
- [ ] **Obsidian** — экспорт заметок в Obsidian vault

### Платформа

- [ ] **FastAPI вместо http.server** — асинхронность, автодокументация, валидация
- [ ] **Web UI** — минимальный дашборд для просмотра обработанных встреч
- [ ] **Очередь задач** — Celery / RQ для фоновой обработки
- [ ] **Мониторинг** — Prometheus метрики + Grafana дашборд

---

## Долгосрочные цели (v1.0+)

### AI-функции

- [ ] **Sentiment analysis** — определение настроения встречи
- [ ] **Decision extraction** — автоматическое выделение принятых решений
- [ ] **Risk detection** — выявление рисков и проблем в обсуждениях
- [ ] **Follow-up reminders** — напоминания о просроченных action items
- [ ] **Meeting score** — оценка эффективности встречи

### Enterprise

- [ ] **Multi-tenant** — поддержка нескольких команд/отделов
- [ ] **RBAC** — ролевая модель доступа
- [ ] **Шифрование** — end-to-end для транскриптов
- [ ] **On-premise Whisper** — полная изоляция данных
- [ ] **API** — публичный REST API для интеграций

### Экосистема

- [ ] **Мобильное приложение** — запись и обработка с телефона
- [ ] **Браузерное расширение** —一键 запись Zoom/Meet/Teams
- [ ] **Telegram-бот** — отправка аудио и получение саммари
- [ ] **Шаблоны отчётов** — настраиваемые форматы вывода
