## Последние изменения

- **Мобильные:** Pinch-to-zoom для Mermaid, исправлен скролл на iOS/Android
- **Стриминг:** MEDIA-токены рендерятся inline во время стриминга
- **Docker:** Уведомления о доступных обновлениях
- **SSO:** Reverse-proxy аутентификация через доверенные заголовки
- **Nix:** Flake + NixOS module
- **Производительность:** Кэширование провайдеров (30s TTL), ускоренная загрузка длинных сессий
- **Безопасность:** CORS preflight fix, исправлен path traversal в загрузках
