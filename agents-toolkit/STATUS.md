# Status: Agents Toolkit

**Обновлено:** 2026-08-13  
**Статус:** 🟢 Активен — исследовательский проект

## Текущее состояние

Набор из 8 оптимизированных AI-агентов для финансового анализа, поиска вакансий, мониторинга событий и генерации контента. Все агенты работают через OpenRouter (Claude Opus 5 Fast).

## Метрики

| Метрика | Значение |
|---------|---------|
| Агентов | 8 |
| Модель | Claude Opus 5 Fast (OpenRouter) |
| Стоимость/мес (оценка) | ~$8.10 (при 3000 вызовов) |
| Экономия vs базовая конфиг | ~40% |
| Кэширование | 2 задачи (HH Jobs, Confidential) |
| Batch-задачи | 2 группы (local + usa stocks) |
| Формат вывода | JSON (6 задач), Text (1), Text+JSON (1) |
