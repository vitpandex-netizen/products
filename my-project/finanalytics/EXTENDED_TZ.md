# FinAnalytics — Расширенное техническое задание

## 1. Модель данных (полная)

### 1.1 Кредиты (15 штук в файле)
```sql
credits:
  id, priority (M/B/C), bank_name, monthly_payment, amount_paid, 
  remaining, interest_rate, debit_date, contract_amount, 
  remaining_principal, total_overpayment, debt_start, debt_end,
  term_months, issue_date, status (active/closed/overdue),
  category (car/mortgage/consumer/credit_card)
```

### 1.2 Поступления
```sql
income:
  id, user_id, type (salary/advance/exchange/other),
  amount, currency (UZS/USD), exchange_rate, date, note
```

### 1.3 Расходы
```sql
expenses:
  id, user_id, category_id, amount, payment_source_id,
  date, note, type (expense/income)
```

### 1.4 Категории расходов (из файла)
- Коммуналка (500K/мес)
- Дорога/бензин/зарядка (500K)
- Культурные мероприятия (1M)
- Посиделки (1M)
- Корзинка (4M)
- Обед (3M)
- Дорожные расходы (1.32M)
- **Плюс все из TZ:** Cash, Гаджеты, Дом, Красота, Медицина, Образование, Обязательные платежи, Одежда, Онлайн покупки, Питание вне дома, Подарки, Покупки, Продукты, Путешествия, Развлечения, Сбережения, Связь, Транспорт, Хобби

### 1.5 Карты/Источники (из файла)
- TBC, InfinCard Black, OCTO ЗП, AVO, Cash, Анор кредитные

### 1.6 Платежный календарь
- До 1-го числа
- До 10-го числа (офб авто + офб + миллий банк)
- До 15-го числа (анорбанки ×5 + даврбанк)
- До 30-го числа (алокабанки ×4 + учтепа)

### 1.7 USD Цели
- Покупка/продажа долларов по курсу
- Закрытие долгов в USD
