4️⃣  MAIN.PY (Основной цикл)
───────────────────────────

Что делает:
- Инициализирует парсер, матчер, ответчик
- Запускает основной цикл
- Логирует процесс

Структура:
```python
def main():
    # 1. Загрузить конфиги
    # 2. Парсить вакансии
    vacancies = parser.search(keywords, min_salary)
    logger.info(f"Found {len(vacancies)} vacancies")

    # 3. Матчить
    matches = [matcher.calculate_match(v) for v in vacancies]
    good = [m for m in matches if m.is_good_match()]
    logger.info(f"Matched {len(good)} vacancies")

    # 4. Отправить ответы
    for match in good:
        if responder.respond(match.vacancy.id):
            logger.info(f"✅ Responded to {match.vacancy.title} at {match.vacancy.company}")

    logger.info("Done!")
```
