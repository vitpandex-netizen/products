КОНТЕКСТ (важно прочитать перед началом):
─────────────────────────────────────────
1. HH.uz с 15.12.2025 закрыл API-авторизацию для соискателей (applicant).
   Официального пути отправлять отклики через API больше НЕ существует.
   Поэтому "AUTO_RESPOND через API" — тупиковая ветка, её нужно убрать.

2. Решение с пользователем (подтверждено): вариант C — полу-авто.
   Парсер + матчер работают полностью автоматически.
   Вместо отправки откликов бот шлёт пользователю в Telegram шортлист
   подходящих вакансий (score >= MIN_MATCH_SCORE). Отклик пользователь
   делает сам, вручную, по ссылке из сообщения.

3. SEARCH_AREA_ID уже исправлен на 97 (вся территория Узбекистана,
   проверено через официальный справочник api.hh.ru/areas). Область 110
   была ошибочной (не Узбекистан) — если увидишь 110 где-то ещё
   в коде/комментариях, тоже поправь на 97.

4. ВАЖНО (обновление 2026-07-27): решено организовать уведомления по
   темам (forum topics) в одной группе Telegram — это будет общий бот
   на ВСЕ будущие проекты, у каждого своя тема, чтобы не мешались в
   одну ленту. Для HH-Jobs тема уже создана: message_thread_id=15,
   группа chat_id=-1004297012607 (не личка 110627043 — это устарело,
   не использовать). Это единый паттерн для всех будущих проектов:
   свой TELEGRAM_THREAD_ID в .env, тот же TELEGRAM_BOT_TOKEN и
   TELEGRAM_CHAT_ID (группы) для всех.

2️⃣ src/responder.py — переписать класс Responder:

        POST https://api.telegram.org/bot{TELEGRAM_BOT_TOKEN}/sendMessage

    - Один Telegram-запрос на вакансию, либо можно собрать все новые
      матчи в одно сообщение (на усмотрение — что проще и надёжнее).
