## Источник данных (Фаза 0, подтверждён реальными curl-запросами)

**`https://uzse.uz/trade_results/`** — публичная страница, `200 OK`, без логина.
Требует браузерный `User-Agent` (иначе `403`).

Структура: div-грид (НЕ таблица), повторяющиеся `.main-ticker-item`, внутри
`.price-value` и `.datetime-value`. Для HMKB: `isu_cd=UZ7011340005`.

Не использовать: `uzse.uz/issuers/` — требует логин.
Не распарсено: `uzse.uz/isu_infos/STK?isu_cd=...` (~93KB, вероятно история
сделок/график) — может пригодиться для исторических данных.

Цена в старом xlsx-снимке (57.96 на 27.02.2026) давно неактуальна — цена
реально движется в течение дня (см. историю ниже), источник живой.

## Найденные и исправленные баги (Claude, после Hermes)

1. **Парсер брал дельту вместо цены.** Регулярка `(\d+[.,]\d+)` требовала
   десятичную точку: целая цена `79` → `None`, а `87 (▼ 4.67)` → `4.67`
   (это изменение, а не цена). Дельта лежит во вложенном
   `<span class="price-down">` внутри `.price-value`, и `get_text()`
   склеивал их. Починено: `_own_text()` берёт только прямые текстовые узлы,
   дробная часть в регулярке стала опциональной.
   *Почему не всплыло раньше:* в Фазе 0 цены были 73.31/91.67 — с точками.
2. **Telegram недоступен из Python при рабочем curl.** DNS отдаёт AAAA-запись
   без маршрута, urllib3 не делает фоллбэк на IPv4 (curl делает).
   Починено: `shared/net.py` → `force_ipv4()`, применимо ко всем проектам
   монорепо.

Битая запись (4.67) из `price_history` удалена.
