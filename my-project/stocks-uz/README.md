# Stocks UZ — мониторинг акций UZSE (Ташкент)

Агент для отслеживания цен и постепенного набора данных по акциям
Республиканской фондовой биржи «Тошкент» (UZSE), без автоматических сделок
(бюджет не выделен — только мониторинг и обучение).

## Функционал (MVP, фаза 1)

- Отслеживание цены одного тикера (старт: `HMKB`, Хамкорбанк)
- Накопление истории цен в SQLite (не просто снимок — временной ряд)
- Telegram-уведомления в тему "Stocks-UZ" (message_thread_id=80)
- Постепенное расширение на топ-10 из 56 тикеров UZSE по мере накопления данных

## Быстрый старт

```bash
cd stocks-uz
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python src/main.py
```

## Данные

Единственный подтверждённый источник тикеров: локальный файл
`~/Downloads/UZSE_tickers_final_27_02_2026.xlsx` (56 тикеров, разовый снимок
цен на 27.02.2026 18:00) — прочитать/записать можно через
`shared/tools/uzse_ticker_file.py`.

**Живой источник актуальных цен НЕ подтверждён** — сайт биржи (сохранённая
копия `~/Downloads/Республиканская фондовая биржа «Тошкент».mhtml`) нужно
исследовать на предмет API/структуры страницы, прежде чем писать парсер
(см. HERMES_TASK.md).

## Стратегия

Фундаментальный/долгосрочный подход (не спекулятивный технический анализ) —
предложено исходя из того, что бюджета на сделки нет и рынок UZSE тонкий
(ликвидность не проверена). Пользователь пока не подтвердил явно, стратегия
может измениться.
